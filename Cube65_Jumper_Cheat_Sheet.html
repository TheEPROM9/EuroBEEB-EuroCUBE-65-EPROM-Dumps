Cube-65 / EuroBEEB jumper settings — plain English

OPEN / off   o   o   (no link)
MADE / on   o===o   (link fitted)
Bottom line for a normal Issue 5 EuroBEEB: L6–L9 all open (Map 0). Leave L1 alone. Leave L2/L3 and L5 as supplied unless you know you need differential serial or have fitted the 7660 -5 V inverter. Use L4 only if you deliberately want serial BREAK to reset the machine. None of these jumpers selects the LCD or keyboard — that is software (*FX3,0, *FX2,0).

Quick table

LinkWhat it really doesNormal settingChange it when…
L1Obsolete on Issue 5.Ignore / not usedNever.
L2, L3Ties the negative inputs of the differential serial receivers to 0 V, giving simple single-ended RS-423.As supplied (single-ended serial)You are wiring true differential RS-422 and need both wires of each pair.
L4Connects serial receive/BREAK to the reset line.OPENYou want remote reset from the serial port. Warning: manual reset then cannot be used.
L5Feeds -5 V from expansion bus pin 4b to the serial buffer chips.MADE (no onboard inverter)You fit IC13 7660 with C24/C25 — then break L5.
L6–L94-bit memory-map selector. L6=1, L7=2, L8=4, L9=8.ALL OPEN = Map 0You deliberately want another memory map.

L4 — reset source

  manual reset input             serial receiver / BREAK
  (VIA pin 23 or west pin of L4)        |
            o--------- L4 --------------o

  L4 OPEN   o   o     manual reset works; serial BREAK does not
  L4 MADE   o===o     serial BREAK resets; manual reset disabled

L5 — where the serial chips get -5 V

  expansion bus pin 4b (-5 V) o--- L5 ---o serial buffers

  No 7660 fitted:   MADE   o===o   (normal)
  7660 + C24/C25:   BREAK  o   o   (use the onboard inverter instead)

L2 / L3 — single-ended vs differential serial

  RS-423 single ended (normal/simple)

  signal ----------> positive input
  0 V ------ L2/L3 -> negative input


  RS-422 differential (special case)

  pair + -----------> positive input
  pair - -----------> negative input     L2/L3 open

L6–L9 — memory map as a binary number

        L9  L8  L7  L6
weight   8   4   2   1

  Map 0  .   .   .   .     all open  <-- EuroBEEB normal
  Map 12 #   #   .   .     L9+L8 made, L7+L6 open

# = link made/closed, . = link open.

Memory sockets M0–M3 / M2 EPROM conversion

  Each socket has 9 wire-wrap links defining the chip type.
  Issue 5 M2 is normally linked for a 5565 8K RAM.

  To fit a 2764 8K EPROM in M2:
    wire-wrap version : rewire 5565 connections to 2764 pinout
    tracked version   : link A to B to C
                        drill hole D to 1 mm (no larger)
                        cut track E

M4 is the fused-link PROM version number, not a user jumper.

Serial handshake shortcut (cable/plug link, not a PCB jumper)

  7-pin DIN on EuroCUBE
    1 TxD
    2 0 V
    3 RxD
    4 BUSY / RTS
    5 CTS
  
  No handshake needed: short pins 4 and 5 locally.
  DSR / DCD / DTR: short or hold active as required.
